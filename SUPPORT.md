# Support

Use [GitHub Discussions](https://github.com/MADPANDA3D/FFMPEG-MCP/discussions) for setup questions and integration ideas. Use [GitHub Issues](https://github.com/MADPANDA3D/FFMPEG-MCP/issues) for reproducible bugs and feature requests.

Before opening an issue, check the latest release, run the health check, review container logs with secrets redacted, and include the deployment mode, operating system, Python or image version, and minimal reproduction.

Security reports belong in GitHub's private vulnerability-reporting flow described in [SECURITY.md](SECURITY.md).
